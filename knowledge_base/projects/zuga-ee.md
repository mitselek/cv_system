## et

### Projekt

Zuga.ee on kõrge-jõudlusega kahelingne (eesti/inglise) portfoolio-veebisait, mis esitab Ühendatud Tantsijate teatri tantsulavastusi, etendusi ja töötube.

### Kirjeldus

Ehitasin ja arhitektuurisin Phase 1 implementatsiooni:

**Tehniline Eesmärk:**
- Lighthouse Performance ≥90
- Accessibility 100
- <2s lehekülgekoormus 3G-l
- Täielik tüübiturvalisus (TypeScript strict mode)
- Sisust taastasuvad HTML-failid (Markdown/YAML allikas)

**Implementatsioon:**
- **Framework:** Astro 4.x SSG (staatiliste lehtede generaator)
- **Andmed:** 35+ Markdowni lehekülge (ettekanded, workshopid, teave)
- **Valideerimis:** Zod skeemid käitusajal sisusisu kontrollimiseks
- **Kujundus:** Tailwind CSS utiliitide-esimesed muudatused
- **Jätkuvus:** Netlify juurutamine + GitHub Actions automatiseeritud testid
- **Artefaktid:** Phase 1 arhitektuur, implementatsiooniplaanid, konstitutsioon

### Saavutused

- Arhitektuuri disain rangete jõudluse ja ligipääsetavuse kriteeriumitega
- Bilingvaalse sisuhalduse süsteem (eesti/inglise keeli)
- Tüübiturvalisuse jõustamine kogu koosteplanni (TypeScript + Zod)
- Git workflow dokumenteerimisega ja pre-commit hooks-iga
- Constitutional principles (§1-§5): tüübiturvalisus esimesena, test-first arendus, composable arhitektuur

### Tehniline Stack

- Astro 4.x: Staatiliste lehtede generaator (Phase 1)
- TypeScript: Strict tüüpide kontroll
- Tailwind CSS: Utiliitide-esimesed stiilid
- Zod: Käitusaja sisusisu valideerimis
- Markdown + YAML: Sisu allikafail
- Netlify: Hosting ja pidev juurutamine
- GitHub Actions: Automatiseeritud testid ja juurutamine

### Tulevikus

- Phase 2: AI Assistant frontend sisusisu halduseks
- Phase 3: Dünaamilised omadused ja kasutaja interaktsioonid

## en

### Project

Zuga.ee is a high-performance bilingual (Estonian/English) portfolio website showcasing dance performances, shows, and workshops by United Dancers Theatre.

### Description

Architected and implemented Phase 1 of the project:

**Technical Objectives:**
- Lighthouse Performance ≥90
- Accessibility 100
- <2s page load on 3G
- Complete type safety (TypeScript strict mode)
- Regeneratable HTML from Markdown/YAML source

**Implementation:**
- **Framework:** Astro 4.x SSG (static site generator)
- **Content:** 35+ markdown pages (performances, workshops, information)
- **Validation:** Zod schemas for runtime content validation
- **Styling:** Tailwind CSS utility-first approach
- **Deployment:** Netlify hosting + GitHub Actions automated testing
- **Documentation:** Phase 1 architecture, implementation plans, constitution

### Achievements

- Architecture design with strict performance and accessibility requirements
- Bilingual content management system (Estonian/English languages)
- Type safety enforcement across entire build pipeline (TypeScript + Zod)
- Git workflow documentation with pre-commit hooks
- Constitutional principles (§1-§5): type safety first, test-first development, composable architecture

### Technical Stack

- Astro 4.x: Static site generator (Phase 1)
- TypeScript: Strict type checking
- Tailwind CSS: Utility-first styling
- Zod: Runtime content validation
- Markdown + YAML: Content source format
- Netlify: Hosting and continuous deployment
- GitHub Actions: Automated testing and deployment

### Future Phases

- Phase 2: AI Assistant frontend for content management
- Phase 3: Dynamic features and user interactions
